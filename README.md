# Exercícios de JavaScript - Manipulação do DOM

## 📖 Sobre o Projeto

Este repositório reúne uma série de exercícios desenvolvidos com **HTML, CSS e JavaScript**, com o objetivo de praticar conceitos fundamentais de desenvolvimento web e manipulação do DOM (Document Object Model).

Os projetos foram desenvolvidos como parte dos estudos de programação front-end, abordando eventos, interação com o usuário, atualização dinâmica da interface e lógica de programação.

---

# 🚀 Projetos Desenvolvidos

## 1️⃣ Contador

### Descrição

Aplicação simples para incrementar e decrementar valores através de botões.

### Funcionalidades

* Incrementar o contador.
* Decrementar o contador.
* Atualização dinâmica do valor exibido.

### Conceitos Aplicados

* `getElementById()`
* `addEventListener()`
* Manipulação de texto com `textContent`
* Variáveis e operadores matemáticos

---

## 2️⃣ Interruptor de Lâmpada

### Descrição

Projeto que simula um interruptor de luz, alterando a imagem da lâmpada entre os estados ligada e desligada.

### Funcionalidades

* Acender a lâmpada.
* Apagar a lâmpada.
* Troca dinâmica de imagens.
* Interação visual com o usuário.

### Conceitos Aplicados

* Manipulação de atributos HTML.
* Alteração do atributo `src`.
* Eventos de clique.
* Interação com imagens.

---

## 3️⃣ Lista de Compras

### Descrição

Aplicação para adicionar e remover itens dinamicamente de uma lista de compras.

### Funcionalidades

* Adicionar novos itens.
* Remover itens individualmente.
* Limpeza automática do campo de entrada.
* Atualização dinâmica da lista.

### Conceitos Aplicados

* `createElement()`
* `appendChild()`
* `remove()`
* `trim()`
* Manipulação dinâmica do DOM.

---

## 4️⃣ Calculadora

### Descrição

Calculadora funcional desenvolvida para realizar operações matemáticas básicas através de uma interface simples e intuitiva.

### Funcionalidades

* Operações de soma, subtração, multiplicação e divisão.
* Botão de limpar display (C).
* Botão de apagar último caractere (⌫).
* Avaliação dinâmica de expressões matemáticas.
* Tratamento de erros para expressões inválidas.

### Conceitos Aplicados

* `getElementById()`
* `onclick`
* Manipulação de inputs com `value`
* `eval()`
* Manipulação de strings
* `slice()`
* Tratamento de exceções com `try/catch`

---

# 🎯 Objetivos de Aprendizagem

Durante o desenvolvimento destes exercícios foram praticados os seguintes conceitos:

* Estruturação de páginas web com HTML.

* Eventos e interação com o usuário.

* Organização de código JavaScript.
